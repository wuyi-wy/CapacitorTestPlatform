# SerialPortWPF 上位机功能与设备指令说明

## 一、整体功能概述

本系统是一个基于 WPF 的串口上位机应用，用于连接和控制多种绝缘测试仪器设备，实现参数配置、数据采集和结果保存的自动化。

### 核心功能模块

| 模块         | 功能说明                                                     |
| ------------ | ------------------------------------------------------------ |
| 串口通信     | 打开/关闭串口，选择串口号和波特率，刷新可用端口列表，发送 SCPI 指令并接收设备响应 |
| 参数配置     | 向设备发送配置指令，设置测试参数（电压、电流、频率、速度等） |
| 数据读取     | 触发设备执行测试，读取绝缘电容（LC）和绝缘电阻（IR）等测量结果 |
| 数据存储     | 将检测结果保存至 SQLite 本地数据库，支持单次和列表扫描批量保存 |
| 检测项目管理 | 在 `TBL_CHECKPROJECT` 表中注册检测编号，关联检测数据         |

### 系统架构

- **MVVM 模式**：ViewModel 继承 `DeviceBaseViewModel`，共享串口打开/关闭、波特率选择、刷新端口、配置/读取/保存等操作
- **数据库**：SQLite 本地数据库，包含检测项目表 + 6 张设备专用数据表
- **串口通信服务**：`SerialPortService` 封装 `System.IO.Ports.SerialPort`，使用换行符 `\n` 作为指令分隔符

## 二、各设备功能与指令详情

### 1. TH2689 - 绝缘测试仪

#### 功能描述

- 专用于薄膜/纸基材料的绝缘性能测试
- 支持正向/反向两种测试方向
- 正向测试读取 LC（绝缘电容）和 IR（绝缘电阻）
- 反向测试读取 LCf（反向绝缘电容）和 IRf（反向绝缘电阻）
- 充电时间（ChgTime）和延迟时间（Dweli）参数可调
- 支持自动/手动量程切换

#### 可配置参数

| 参数      | 下拉选项                        | 有效范围 | 说明                       |
| --------- | ------------------------------- | -------- | -------------------------- |
| Voltage   | 自定义输入                      | 1~800    | 测试电压 (V)               |
| Current   | 自定义输入                      | 0.5~500  | 测试电流                   |
| Function  | SEQ / STEP / CONT               | -        | 测试模式（顺序/步进/连续） |
| Speed     | FAST / MEDium / SLOW            | -        | 测试速度                   |
| Range     | 2uA / 20uA / 200uA / 2mA / 20mA | -        | 电流量程                   |
| ChgTime   | 自定义输入                      | 0~999    | 充电时间 (s)               |
| Dweli     | 自定义输入                      | 0.2~999  | 延迟时间 (s)               |
| RangeAuto | OFF / ON                        | -        | 自动量程                   |

#### 输出结果

- **LC** - 绝缘电容值
- **LCf** - 反向绝缘电容值
- **IR** - 绝缘电阻值
- **IRf** - 反向绝缘电阻值

#### SCPI 指令

| 序号 | 指令                                       | 说明               |
| ---- | ------------------------------------------ | ------------------ |
| 1    | `:DISPlay:STATe?`                          | 查询当前显示状态   |
| 2    | `:DISPlay:LCTest`                          | 切换到 LC 测试页面 |
| 3    | `:LCTest:SOURce:VOLTage {Voltage}`         | 设置测试电压       |
| 4    | `:LCTest:SOURce:CURRent {Current}`         | 设置测试电流       |
| 5    | `:LCTest:CONFigure:FUNCtion {Function}`    | 设置测试模式       |
| 6    | `:LCTest:CONFigure:SPEed {Speed}`          | 设置测试速度       |
| 7    | `:LCTest:CONFigure:RANGe {rangeIndex}`     | 设置电流量程索引   |
| 8    | `:LCTest:CONFigure:CHGTime {ChgTime}`      | 设置充电时间       |
| 9    | `:LCTest:CONFigure:DWELl {Dweli}`          | 设置延迟时间       |
| 10   | `:LCTest:CONFigure:RANGe:AUTO {RangeAuto}` | 设置自动量程       |
| 11   | `:LCTest:MEASure:IR?`                      | 读取绝缘电阻值     |
| 12   | `:LCTest:MEASure:LC?`                      | 读取绝缘电容值     |

#### 数据库表

`TBL_CHECKDATA_TH2689` — checkNumber, LC, IR, fir(IRf), lcf, checkUser, checkDate, checktime

### 2. TH2683A - 耐压/绝缘电阻测试仪

#### 功能描述

- 支持 100V/500V 两档测试电压
- 支持单次（Single）和连续（Continuous）测试模式
- 可配置加压时间、检测时间、检测速度、等待时间、放电时间
- 打开串口时自动切换到 MEAS 页面

#### 可配置参数

| 参数        | 下拉选项            | 说明     |
| ----------- | ------------------- | -------- |
| Voltage     | 100v / 500v         | 测试电压 |
| CurrentTime | 自定义输入          | 加压时间 |
| CheckTime   | 自定义输入          | 检测时间 |
| CheckSpeed  | FAST / SLOW         | 检测速度 |
| WaitTime    | 自定义输入          | 等待时间 |
| Mode        | SINGle / CONTinuous | 测试模式 |
| FreeTime    | 自定义输入          | 放电时间 |

#### 输出结果

- **LC** - 绝缘电容值 (μF)，内部将原始值 × 1000000 转换
- **IR** - 绝缘电阻值 (MΩ)，内部将原始值 / 1000000 转换

#### 前置检查

配置前查询 `SYSTem:STSTus?`，若设备处于 "DISCharging" 或 "TESTing" 状态则提示用户等待

#### SCPI 指令

| 序号 | 指令                            | 说明                          |
| ---- | ------------------------------- | ----------------------------- |
| 1    | `SYSTem:STSTus?`                | 查询设备状态（放电中/测试中） |
| 2    | `DISPlay:PAGE MSETup`           | 切换到测量设置页面            |
| 3    | `DISP:PAGE MEAS`                | 打开串口时切换至测量页面      |
| 4    | `:FUNCtion:OVOLTage {Voltage}`  | 设置测试电压                  |
| 5    | `:FUNCtion:CTIMe {CurrentTime}` | 设置加压时间                  |
| 6    | `:FUNCtion:MTIMe {CheckTime}`   | 设置检测时间                  |
| 7    | `:FUNCtion:MSPeed {CheckSpeed}` | 设置检测速度                  |
| 8    | `:FUNCtion:MMode {Mode}`        | 设置测试模式                  |
| 9    | `:FUNCtion:WTIMe {WaitTime}`    | 设置等待时间                  |
| 10   | `:FUNCtion:DTIMe {FreeTime}`    | 设置放电时间                  |
| 11   | `fetc?`                         | 获取测量结果（LC, IR）        |

#### 数据库表

`TBL_CHECKDATA_TH2683A` — checkNumber, LC, IR, checkUser, checkDate, checktime

### 3. TH2817A - 介电常数/绝缘电阻测试仪

#### 功能描述

- 支持多种阻抗参数测试功能（CPD/CSD/CSRS/LPQ/LSRS/ZTD/ZTR/RX）
- 支持扫频模式（List Frequency），可设置多个频率点自动扫描
- 单次测试和列表扫描两种模式
- 列表扫描时自动切换到 LISTSWEEP 页面，等待约 8 秒完成扫频

#### 可配置参数

| 参数          | 下拉选项                                       | 说明                 |
| ------------- | ---------------------------------------------- | -------------------- |
| Function      | CPD / CSD / CSRS / LPQ / LSRS / ZTD / ZTR / RX | 阻抗测试功能         |
| Frequency     | MIN ~ 100kHz 共 18 档                          | 测试频率             |
| ListFrequency | 逗号分隔的频率列表                             | 扫频模式下的频率序列 |

#### 输出结果

- **LC** - 电容值
- **IR** - 绝缘电阻值

#### SCPI 指令

| 序号 | 指令                        | 说明             |
| ---- | --------------------------- | ---------------- |
| 1    | `DISPlay:PAGE?`             | 查询当前页面状态 |
| 2    | `DISPlay:PAGE MeAsurement`  | 切换到测量页面   |
| 3    | `FUNC:IMP {Function}`       | 设置阻抗测试功能 |
| 4    | `FREQUENCY {Frequency}`     | 设置测试频率     |
| 5    | `DISPlay:PAGE LIST`         | 切换到列表页面   |
| 6    | `LIST:FREQ {ListFrequency}` | 设置扫频频率列表 |
| 7    | `TRIG:Source BUS`           | 设置触发源为总线 |
| 8    | `TRIG`                      | 触发测试         |

#### 数据库表

`TBL_CHECKDATA_TH2817A` — checkNumber, data1, data2, frequercy, func, checkUser, checktime, checkDate

### 4. TH2832 - 绝缘电容/电阻测试仪

#### 功能描述

- 与 TH2817A 类似，支持多种阻抗功能测试
- 额外支持 **列表电压**（ListVoltage）设置，实现频率-电压联合扫描
- 支持薄膜/纸基绝缘电阻模式提醒
- 列表模式下自动切换到 LIST 页面

#### 可配置参数

| 参数          | 下拉选项                                                     | 说明                                      |
| ------------- | ------------------------------------------------------------ | ----------------------------------------- |
| Function      | CPD / CSD / CSRS / LSRS / LPQ / ZTD / ZTR / RX               | 阻抗测试功能                              |
| Frequency     | MIN ~ 100kHz 共 18 档                                        | 测试频率                                  |
| Voltage       | 10mV / 20mV / 100mV / 200mV / 300mV / 500mV / 1V / 2V        | 测试电压                                  |
| Speed         | FAST / MED / SLOW                                            | 测试速度                                  |
| Range         | 3 / 10 / 30 / 100 / 300 / 1000 / 3000 / 10000 / 30000 / 100000 / AUTO | 量程                                      |
| ListFrequency | 逗号分隔的频率列表                                           | 扫频频率（需含逗号才启用列表模式）        |
| ListVoltage   | 逗号分隔的电压列表                                           | 扫频电压（需含逗号才启用列表模式）        |
| Mode          | 自定义文本                                                   | 绝缘类型提示（薄膜绝缘电阻/纸基绝缘电阻） |

#### 输出结果

- **LC** - 绝缘电容值 (μF)，内部将原始值 × 1000000 转换，精度 F3
- **IR** - 绝缘电阻值 (MΩ)，内部将原始值 × 1 转换，精度 F5

#### SCPI 指令

| 序号 | 指令                        | 说明                          |
| ---- | --------------------------- | ----------------------------- |
| 1    | `DISPlay:PAGE MeAsurement`  | 切换到测量页面                |

| 3    | `FREQUENCY {Frequency}`     | 设置测试频率                  |

| 5    | `APER {Speed}`              | 设置测量速率                  |

| 7    | `FUNC:IMP:RANG {Range}`     | 设置固定量程                  |

| 12   | `TRIG`                      | 触发单次测试                  |
| 13   | `FETC?`                     | 获取测量结果                  |

#### 数据库表

`TBL_CHECKDATA_TH2832` — checkNumber, data1, data2, frequercy, func, checkUser, checkDate, checktime

### 5. TH9201 - 安规测试仪（阶梯式测试）

#### 功能描述

- 支持 **AC（交流）、DC（直流）、IR（绝缘电阻）、OS（短路）** 四种测试步骤
- 每步可独立设置电压上下限、测试时间
- 测试结果映射为 5 种状态：PASS / HIGH FAIL / LOW FAIL / ARC FAIL / RANGE FAIL
- 使用静态步进号 `_stepNum` 追踪当前配置步骤

#### 可配置参数

| 参数  | 下拉选项           | 说明         |
| ----- | ------------------ | ------------ |
| Step  | AC / DC / IR / OS  | 测试步骤类型 |
| Volt  | 自定义输入         | 测试电压等级 |
| Upper | 自定义输入         | 上限值       |
| Lower | 自定义输入，默认 0 | 下限值       |
| Time  | 自定义输入         | 测试时间     |

#### 测试结果映射

| fetch 返回值 | 显示结果   |
| ------------ | ---------- |
| 1            | PASS       |
| 2            | HIGH FAIL  |
| 3            | LOW FAIL   |
| 4            | ARC FAIL   |
| 5            | RANGE FAIL |
| 其他         | 原始值     |

#### SCPI 指令

| 序号 | 指令                                                 | 说明                                |
| ---- | ---------------------------------------------------- | ----------------------------------- |
| 1    | `:SOUR:SAFE:STEP {_stepNum}:FUNC {funcNum}`          | 设置步骤功能（AC=1/DC=2/IR=3/OS=4） |
| 2    | `:SOUR:SAFE:STEP {_stepNum}:{Step}:LEV {Volt}`       | 设置步骤电压等级                    |
| 3    | `:SOUR:SAFE:STEP {_stepNum}:{Step}:LIM:HIGH {Upper}` | 设置上限                            |
| 4    | `:SOUR:SAFE:STEP {_stepNum}:{Step}:LIM:LOW {Lower}`  | 设置下限                            |
| 5    | `:SOUR:SAFE:STEP {_stepNum}:{Step}:TIME:TEST {Time}` | 设置测试时间                        |
| 6    | `:TEST:FETCH?`                                       | 获取测试结果（PASS/FAIL 状态）      |

#### 数据库表

`TBL_CHECKDATA_TH9201` — checkNumber, step, volt, upper_1, lowr, time_1, fetch_1, checkUser, checkDate, checktime

### 6. TH2810B+ - 绝缘电容/电阻测试仪

#### 功能描述

- 与 TH2832 类似，支持单次测试和列表扫描
- 额外支持 **列表模式**（SEQ/STEP）控制
- 支持频率-电压联合扫频（最少 4 组配对数据）
- **注意**：此设备目前未实现 SaveCmd（保存功能），界面无 Save 按钮

#### 可配置参数

| 参数          | 下拉选项                                                     | 说明                           |
| ------------- | ------------------------------------------------------------ | ------------------------------ |
| Function      | CSD                                                          | 阻抗测试功能（当前仅支持 CSD） |
| Frequency     | 100Hz / 120Hz / 1kHz / 10kHz                                 | 测试频率                       |
| Voltage       | 10mV / 20mV / 50mV / 100mV / 250mV / 500mV / 1V              | 测试电压                       |
| Range         | 3 / 10 / 30 / 100 / 300 / 1000 / 3000 / 10000 / 30000 / 100000 / AUTO | 量程                           |
| Speed         | FAST / MED / SLOW                                            | 测试速度                       |
| ListFrequency | 逗号分隔的频率列表                                           | 扫频频率                       |
| ListVoltage   | 逗号分隔的电压列表                                           | 扫频电压                       |
| Mode          | SEQ / STEP                                                   | 列表模式（顺序/步进）          |

#### 输出结果

- **LC** - 绝缘电容值 (μF)，内部将原始值 × 1000000 转换，精度 F4
- **IR** - 绝缘电阻值 (MΩ)，内部将原始值 × 1 转换，精度 F6

#### 列表模式数据处理

列表模式下每行数据按 `i % 5` 提取：

- `i % 5 == 0` → LC（电容值，× 1000000）
- `i % 5 == 1` → IR（电阻值，× 1）
- 其他索引的数据被忽略

#### SCPI 指令

| 序号 | 指令                        | 说明                     |
| ---- | --------------------------- | ------------------------ |
| 1    | `DISPlay:PAGE MeAsurement`  | 切换到测量页面           |
| 2    | `FUNC:IMP {Function}`       | 设置阻抗测试功能         |
| 3    | `FREQUENCY {Frequency}`     | 设置测试频率             |
| 4    | `VOLTage {Voltage}`         | 设置测试电压             |
| 5    | `FUNC:IMP:RANG:AUTO ON`     | 开启自动量程             |
| 6    | `FUNC:IMP:RANG {Range}`     | 设置固定量程             |
| 7    | `APER {Speed}`              | 设置测量速率             |
| 8    | `DISPlay:PAGE LIST`         | 切换到列表页面           |
| 9    | `LIST:FREQ {ListFrequency}` | 设置扫频频率列表         |
| 10   | `LIST:VOLT {ListVoltage}`   | 设置扫频电压列表         |
| 11   | `LIST:MODE {Mode}`          | 设置列表模式（SEQ/STEP） |
| 12   | `DISPlay:PAGE MEASurement`  | 读取时切换到测量页面     |
| 13   | `TRIG:Source BUS`           | 设置触发源为总线         |
| 14   | `TRIG`                      | 触发测试                 |

#### 数据库表

`TBL_CHECKDATA_TH2810B` — 包含 25+ 个字段，支持完整的设备参数和测试结果存储（checkDate, MAINPARAM, FREQUENCY, LEVEL, RANGE, SPEED, MASTERDATA, SLAVEDATA 等）

## 三、串口通信公共信息

### 支持的波特率

9600 / 19200 / 38400 / 57600 / 115200

### 通信参数

- 数据位：8
- 校验位：None
- 停止位：One
- 指令结尾：`\n`（换行符）
- 读写超时：3000ms

### 各设备默认波特率

| 设备     | 默认波特率 |
| -------- | ---------- |
| TH2689   | 19200      |
| TH2683A  | 9600       |
| TH2817A  | 9600       |
| TH2832   | 115200     |
| TH9201   | 19200      |
| TH2810B+ | 19200      |

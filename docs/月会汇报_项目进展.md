- 业务合并后，设计单位改到检测中心系统提单，不再走原来的筛选系统

## 二、工控示波器平台

### 1. 现场痛点

**流程层面：**

- 每做一个实验，操作员需要手动给示波器波形拍照
- 拍完后在电脑上逐一整理照片、手动录入测试值
- 流程繁琐，容易出错

**硬件层面：**

- 已找计算机中心开了示波器接入办公网的权限，平台可以远程控制示波器
- 但示波器是随设备移动的，电脑是固定的
- 操作员每捕获一次波形就要回到电脑前操作，来回走动耗时
- **自动化平台解决不了这个问题，需要配移动笔记本（双网卡）才行**

### 2. 完成情况

- 基于之前空调控制器项目的示波器自动化平台，切换数据源、优化部分功能，**已可试用**
- 示波器操作没法完全标准化，指令库编辑意义不大，精简为三个核心功能：
  - 停止波形运行
  - 捕获当前波形
  - 自定义命名保存
- 编辑完模板、录入数据后可自动生成 Excel

### 3. 现存问题

| 问题                 | 说明                                             | 解决方向               |
| -------------------- | ------------------------------------------------ | ---------------------- |
| 数据仍需人工录入     | 不编辑指令库，测试值需操作员手动填写             | 平台框架已有，后续可扩展 |
| 设备兼容性有限       | 目前仅 RTM3004 可对接，另外两种示波器仍需手工录入 | 需逐个评估接口协议适配 |
| 关联四代系统未通     | 提交审批逻辑需调整，需检测技术室做信息化开发配合 | 先调通逻辑，再确认排期 |
| 示波器与电脑距离远   | 示波器随设备移动，电脑固定，来回走动影响效率     | 配双网卡移动笔记本     |
| 能否提效待评估       | 之前空调控制器平台已不用，本平台实际效果需验证   | 试用后评估             |

### 4. 下一步

1. 先把提交审批的逻辑调通
2. 跟检测技术室确认四代系统对接排期
3. 评估移动笔记本方案的可行性
4. 试用后评估实际提效效果
